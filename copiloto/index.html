Cómo se calcula el nivel de gravedad

El nivel se calcula sumando una puntuación base más incrementos según la gravedad del impacto real sobre servicios. El resultado final se traduce en N1, N2 o N3.

CondiciónPuntos
Nivel base del escenario (catálogo de escenarios)1 o 2
≥ 3 servicios afectados+0.5
≥ 8 servicios afectados+0.5
≥ 15 servicios afectados+0.5
RTO más exigente ≤ 4 horas+0.5
RTO más exigente ≤ 2 horas+0.5
Pérdida/hora ≥ 1.500 €+0.5
Pérdida/hora ≥ 5.000 €+0.5
≥ 1 servicio crítico afectado+0.5
≥ 4 servicios críticos afectados+0.5
Escenario tipo hostil / proveedor / personas+0.5

Umbrales: Puntuación < 2.5 → N1 · ≥ 2.5 → N2 · ≥ 4 → N3

Escalada automática a N3 si se cumple cualquiera de estas condiciones:

  • Se declara Categoría 3 en algún escenario activo (la gravedad del incidente justifica activar el comité)
  • Se supera el MTPD de algún servicio
  • La pérdida acumulada supera el umbral configurado por el RCN
Ejemplo práctico

Escenario E3 (base N2, sistemas) + 9 servicios afectados + RTO mínimo 3 h + pérdida/hora 2.200 €:

2 (base) + 0.5 (≥3 svc) + 0.5 (≥8 svc) + 0.5 (RTO ≤4h) + 0.5 (pérdida ≥1.500€) = 4.0 → N3 · Escalar a comité
